# 审计材料说明

本目录包含论文现有实验结果的只读审计材料：

- `statistical_uncertainty_report.md`：查询级成对 bootstrap 与区间解释。
- `p_ret_p_gen_equivalence_audit.md`：P_ret/P_gen 查询级接口与结果审计。
- `clean_f1_case_diagnosis.md`：80 例低 Clean F1 诊断。
- `anti_cherrypicking_audit.md`：数据集、检索器、种子和指标覆盖检查。
- `experiment_audit_main.md`：主矩阵运行与输入一致性审计。
- `experiment_audit_control.md`：控制与消融运行审计。
- `gpu_resource_snapshot.md`：4×RTX 3090 环境快照。
- `supplemental_audits.json`：三稿新增的区间端点、共同分母和确定性审计。

这些材料不改变原始 CSV，只用于论文表述核验和复现边界说明。
