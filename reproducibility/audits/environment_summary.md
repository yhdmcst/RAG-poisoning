# 原实验环境摘要

本文件只记录项目冻结审计材料中可核验的环境信息。

- 执行方式：本地 Linux 工作站，无 SSH 远程服务器。
- CPU：64 个逻辑 CPU。
- 可用内存：约 200 GiB。
- GPU：4 张 NVIDIA GeForce RTX 3090。
- 单卡显存：24,576 MiB。
- NVIDIA 驱动：580.119.02。
- 主实验生成器：Qwen3-8B。
- 主实验攻击种子：13、42、2026。
- Python、PyTorch、Transformers、Sentence-Transformers、CUDA 和 cuDNN 的精确版本未在当前提交包中归档，投稿前需从原实验环境补录。
